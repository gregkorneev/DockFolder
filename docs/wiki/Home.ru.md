# Wiki DockFolders

DockFolders — нативное приложение macOS для группировки установленных приложений в пользовательские папки и запуска их из Dock.

## Языки

Интерфейс доступен на английском и русском. DockFolders использует язык, выбранный в настройках macOS. Для количества приложений на русском применяются правильные формы множественного числа.

## Текущий статус

- **Реализовано:** основные функции версии 1.0: CRUD/настройка/сортировка папок, поиск и добавление/удаление/запуск/сортировка приложений, всплывающая панель с учётом Dock, отдельные ярлыки папок, настройки сетки и темы, предпочтения горячей клавиши и запуска при входе, импорт и экспорт.
- **Проверено:** 23 модульных теста; ручной запуск ярлыка через Finder открыл папку Code как при работающем DockFolders, так и после холодного запуска.
- **Не проверено:** несколько дисплеев и все стороны Dock, доступность/уменьшение движения, фактическая регистрация запуска при входе, конфликты горячих клавиш, подпись/нотариальное заверение/sandbox/распространение и закрепление пользователем на чистой установке.
- **Закрепление в Dock:** пользователь добавляет каждый ярлык через интерфейс macOS. DockFolders не редактирует настройки Dock и не использует закрытые API.
- **Размер значка ярлыка:** ярлык каждой папки использует стандартный многослойный по разрешению значок приложения `.icns`; общий размер плиток Dock и увеличение настраиваются в «Рабочий стол и Dock» macOS.
