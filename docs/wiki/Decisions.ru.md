# Архитектурные решения

## D-001 — Нативное приложение SwiftUI/AppKit (принято)

Использовать Swift 6, SwiftUI, публичные API AppKit, системные фреймворки и Codable. Не добавлять сторонние зависимости без подтверждённой необходимости.

## D-002 — Локальное хранение в версионированном JSON (принято для MVP)

Хранить данные пользователя в Application Support и записывать их атомарно. Сохранять исходные данные при ошибках чтения и записи. Модель версии 1.0 должна безопасно мигрировать данные версии 0.1.

## D-003 — Интеграция с Dock сохраняет контроль пользователя (принято)

На этапе A используется обычный значок приложения в Dock, на этапе B — отдельные приложения-ярлыки папок. macOS документирует действия пользователя, например **Options → Keep in Dock**. `NSDockTile` в AppKit настраивает плитку приложения/окна, но не предоставляет публичный API для закрепления произвольного элемента. Поэтому пользователь добавляет каждый ярлык стандартными средствами macOS. Не редактировать настройки Dock, не использовать закрытые API и автоматизацию интерфейса. См. [интеграцию с Dock](Dock-Integration.md) и [руководство Apple по Dock](https://support.apple.com/en-gb/guide/mac-help/mh35859/27/mac/27).

## D-004 — Схема URL для маршрутизации ярлыков (принято)

Использовать проверенный URL `dockfolders://folder/<UUID>` для открытия папки из ярлыка. Ярлык вручную проверен, когда основное приложение работало и при холодном запуске. До выпуска нужно продолжить проверку подписи и sandbox; UUID не является разрешением на несвязанные действия.

## D-005 — Всплывающее окно с учётом Dock (реализовано; геометрия проверяется)

Использовать панель AppKit с интерфейсом SwiftUI и позиционировать её относительно геометрии Dock/экрана. Escape, потеря фокуса и успешный запуск приложения закрывают окно. Требуется вручную проверить несколько дисплеев, стороны Dock, автоскрытие и изменение конфигурации дисплея.

## D-006 — Закрепление в Dock выполняет пользователь (принято)

Ярлыки создаются в `/Applications/DockFolders`; пользователь открывает каждый ярлык и выбирает **Options → Keep in Dock**. Не изменять настройки Dock и не автоматизировать интерфейс.

## D-007 — Политика распространения пока не определена

Текущая локальная сборка не предназначена для выпуска. Решение о подписи/нотариальном заверении и sandbox принять после проверки поиска приложений, bookmarks/разрешений и установки ярлыков.
