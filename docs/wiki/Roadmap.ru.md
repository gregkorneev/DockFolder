# Дорожная карта

Статус: основная реализация включает запрошенный объём версий 0.1, 0.2 и 1.0. Остаются проверки конкретного хоста и подготовка к распространению, а не основная очередь функций.

## Версия 0.1 — Основа (реализовано)

- Основное приложение, CRUD папок, поиск/добавление/удаление/запуск установленных приложений.
- Версионированное локальное хранение JSON и обработка ошибок.

## Версия 0.2 — Интеграция с Dock (реализовано)

- Отдельный ярлык `.app` для каждой папки в `/Applications/DockFolders`.
- Проверенная маршрутизация `dockfolders://folder/<UUID>` открывает выбранную папку.
- Ручная проверка через Finder охватила работающий и холодный запуск.
- Пользователь сам добавляет ярлык в Dock через интерфейс macOS; настройки Dock не редактируются.

## Версия 1.0 — Основные функции реализованы

- Настройка SF Symbol/цвета папок и изменение порядка папок/приложений перетаскиванием.
- Всплывающая панель Liquid Glass с учётом Dock, закрываемая через Escape, при потере фокуса и после успешного запуска.
- Настройки сетки/значков/темы, горячая клавиша Control–Option–Space, запуск при входе через `SMAppService`, импорт и экспорт.
- Пройдены 22 модульных теста, включая миграцию, проверку URL, ярлыки, порядок и перенос конфигурации.

## Оставшиеся проверки выпуска

- Несколько дисплеев, все стороны Dock, скрытый Dock и смена конфигурации экрана.
- Доступность, VoiceOver, работа только с клавиатурой, контраст и уменьшение движения.
- Фактическая регистрация запуска при входе, конфликты горячих клавиш и инструкции по закреплению на чистой установке.
- Подпись, нотариальное заверение, политика sandbox и пакетные установка/обновление/удаление.
