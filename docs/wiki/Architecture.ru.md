# Архитектура

## Текущая реализация

- **Платформа:** macOS 27.0+, Apple Silicon, Swift 6, Xcode 27.1 / SDK 27.
- **Структура приложения:** основное приложение и отдельное приложение-ярлык с названием каждой папки в `/Applications/DockFolders` (при совпадении названий добавляется номер). Переименование меняет имя ярлыка, сохраняя проверенный URL `dockfolders://folder/<UUID>`. Пользователь, а не DockFolders, закрепляет ярлык в Dock.
- **Интерфейс:** SwiftUI управляет папками, настройками и сеткой приложений. AppKit `NSPanel` показывает всплывающую панель с учётом Dock и закрывает её при Escape, потере фокуса или успешном запуске приложения. AppKit также отвечает за жизненный цикл и запуск приложений.
- **Данные:** записи папок и настройки Codable хранятся локально в версионированном JSON. Запись атомарная. JSON версии 0.1 мигрируется к расширенной модели; при ошибках декодирования или импорта данные пользователя сохраняются.
- **Записи приложений:** хранят стабильные идентификаторы, отображаемые имена, bundle identifier при наличии и резервный путь. Не сериализуйте `NSImage` и другие временные объекты фреймворков.
- **Поиск приложений:** каталоги `/Applications`, `/System/Applications` и `~/Applications` сканируются в фоне до глубины четырёх уровней; доступен явный выбор приложения. Скрытые пути и содержимое пакетов пропускаются; `.app` фильтруются и устраняются дубликаты по нормализованному URL. Более глубокие папки и съёмные тома не сканируются.
- **Запуск:** используются публичные API открытия приложений `NSWorkspace`; ошибка показывается, если приложение удалено или перемещено.
- **Настройки:** сохраняются значок, цвет и порядок папок, порядок приложений, размеры сетки и значков, тема, предпочтения горячей клавиши и запуска при входе. Статус регистрации ОС отделён от сохранённого предпочтения.
- **Интеграции:** ярлыки используют проверенные пользовательские URL; глобальная клавиша Control–Option–Space использует Carbon; запуск при входе использует `SMAppService`. Конфликты и фактическая регистрация ОС ещё не проверены.
- **Хранение:** узкий протокол репозитория позволяет подменить JSON-ввод/вывод в модульных тестах. Другие протоколы добавляются только на тех границах ОС, где нужны тестовые подмены.
- **Распространение:** MVP — локальная сборка для разработки без App Sandbox, чтобы находить и открывать установленные приложения. Возможность sandbox для App Store, security-scoped bookmarks и политика подписи/распространения требуют отдельного решения до выпуска.
- **Liquid Glass:** `.glassEffect` собирается с выбранным macOS 27 SDK и используется во всплывающем окне и сетке приложений.

## Оставшиеся проверки и задачи

- Проверить геометрию всплывающего окна на нескольких дисплеях и у всех сторон Dock, включая скрытый или перемещённый Dock и изменения дисплеев.
- Проверить VoiceOver, управление только клавиатурой, уменьшение движения и контрастность.
- Проверить регистрацию и отмену запуска при входе через ServiceManagement на целевом компьютере, а также обработку конфликтов горячих клавиш.
- Определить политику подписи, нотариального заверения, sandbox и распространения. Текущая локальная сборка не является проверенным релизным пакетом.
- Проверить восстановление ссылок на недоступные приложения и сообщения об удалении ярлыка из Dock.

## Основные компоненты

- `DockFoldersApp`: вход в приложение и повторное открытие окна.
- `Models`: значения папок и записей приложений.
- `ViewModels`: наблюдаемое состояние папок и поиск приложений.
- `Views`: список папок, содержимое папки, выборщик/сетка приложений, всплывающее окно и настройки.
- `Services`: поиск и запуск приложений, хранение данных, создание ярлыков и перенос конфигурации.
- `Managers`: всплывающая панель/активация Dock, глобальная клавиша и запуск при входе.
- `Utilities`: небольшие общие помощники, а не универсальный фреймворк.
- `DockFoldersTests`: тесты моделей, хранилища и view model/service.

## Открытие наведением

`DockHoverMonitor` слушает глобальные и локальные события `NSEvent.mouseMoved`, а затем определяет элемент Dock через публичный Accessibility hit-test API. Идентификатор пакета ярлыка сопоставляется с UUID папки, после чего используется существующий `PopupWindowManager`; настройки Dock и закрытые API не затрагиваются. По умолчанию папки открываются нажатием. Режимы с наведением имеют настраиваемые задержки открытия и закрытия и запрашивают только разрешение «Универсальный доступ». При движении курсора hit-test ограничен примерно 30 проверками в секунду; резервный адаптивный опрос включается только если системные мониторы событий установить не удалось. На macOS 27 вручную проверена работа закреплённого ярлыка Code: наведение открывает папку, переход курсора оставляет её открытой, уход закрывает. Другие дисплеи и расположения Dock требуют проверки на целевом компьютере.

## Проверка

- Сборка macOS проходит с Xcode 27.1 / SDK 27.0.
- Пройдены 25 модульных тестов, включая адаптивный размер popup, расчёты положения окна для Dock снизу/слева/справа и запасной вариант, если системный отступ Dock не сообщается.
- Ручная проверка через Finder подтвердила открытие папки Code из ярлыка, когда DockFolders уже запущен и после холодного запуска.
- Фактическое положение popup на нескольких физических дисплеях, доступность/уменьшение движения, регистрация ServiceManagement, конфликты горячих клавиш, production-подпись и sandbox распространения не проверены.
