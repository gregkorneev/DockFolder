# Рабочий процесс Git

- Владелец проекта попросил выполнять всю работу непосредственно в `main`.
- Создавайте небольшие цельные коммиты с префиксами Conventional Commit (`feat:`, `fix:`, `test:`, `docs:`, `chore:`).
- Перед публикацией этапа проверьте diff, выполните подходящие проверки, обновите Wiki/историю изменений и убедитесь, что в коммит не попадут секреты и сгенерированные артефакты сборки.
- Отправляйте завершённые изменения в `origin/main`; не выполняйте force-push и не переписывайте общую историю.
- Точно сообщайте ветку, коммит, результат push, тесты и непроверенное поведение.
- Каноническая документация находится в `docs/wiki/`. Если Wiki GitHub опубликована, синхронизируйте её копией этих файлов, а не ведите отдельные версии.

Правила для участников проекта см. в [AGENTS.md](../../AGENTS.md).
