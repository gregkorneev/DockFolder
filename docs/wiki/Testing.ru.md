# Тестирование

## Записанные результаты проверок

- Сборка и тесты схемы macOS успешно пройдены в Xcode 27.1 / SDK 27.0.
- Пройдены 35 модульных тестов в Debug, включая адаптивный размер popup для столбцового макета и ограниченной области экрана, динамический подбор вместимости сетки и автоматическое увеличение, проверку квадратного исходного изображения ярлыка 1024 × 1024 px при разрешении 2× (512 pt), расчёты popup для всех краёв Dock и схлопывание панели к значку Dock, миграцию JSON, проверку URL, создание ярлыков, сортировку, перенос конфигурации, хранение, поиск и ошибки запуска.
- Тест пользовательской сетки проверяет отдельное сохранение строк/столбцов, вместимость при избытке приложений и ограничения 1–10. Новые текстовые поля и прокрутка ещё не проверены вручную в запущенном приложении.
- Ручная проверка UI: создана папка, найден и добавлен Calculator, приложение запущено, сохранение папки подтверждено после перезапуска.
- Ручная проверка ярлыка: приложение открыто через Finder и выбрало папку Code как при запущенном DockFolders, так и после холодного старта.
- На текущем дисплее вручную открыта папка Code с пятью приложениями в столбец; все значки поместились в popup без прокрутки.

Приложение Beta 2 в конфигурации Release собрано с Xcode 27.1 / Swift 6.4 / macOS 27.0 SDK для arm64 с минимальной версией macOS 27.0. Строгая проверка его временной подписи прошла. `hdiutil verify` подтвердил контрольную сумму DMG; после подключения образа проверены приложение, ярлык `/Applications` и инструкции на двух языках, а также подпись приложения внутри образа. Все 35 тестов Debug прошли; тесты в конфигурации Release не запускались. Чистая установка, обновление, Gatekeeper и нотариальное заверение не проверялись. Ручная проверка новых полей сетки и прокрутки ещё требуется.

## Явно не проверено

Фактический адаптивный размер и обрезка popup на нескольких физических дисплеях, все стороны Dock, скрытый/автоматически скрываемый Dock и подключение/отключение дисплея; VoiceOver, работа только с клавиатурой и поведение с включённым «Уменьшением движения»; регистрация/отмена запуска при входе через перезапуск; конфликты горячих клавиш; очистка устаревших значков Dock; подпись/нотариальное заверение/sandbox/распространение; инструкции закрепления на чистой установке пока не проверены. Адаптивный размер, геометрия краёв Dock и целевое преобразование анимации покрыты модульными тестами; работу на реальном хосте ещё нужно проверить вручную.

## Оставшаяся матрица

- Popup: доступная геометрия экрана у всех сторон Dock, скрытый Dock, несколько дисплеев, отключение/подключение и изменение масштаба.
- Настройки: включение/отключение запуска при входе/ошибка после перезапуска; конфликт и повторная регистрация горячей клавиши.
- Интерфейс/доступность: клавиатура, VoiceOver-подписи, размер текста, контраст и уменьшение движения.
- Ярлыки: переименование/удаление, предупреждение об устаревшем Dock-элементе, установка/обновление/удаление вне среды разработки.
- Выпуск: подпись/нотариальное заверение, выбранная политика sandbox, чистая пакетная установка/обновление/удаление.

Выполняйте только проверки, поддерживаемые окружением; записывайте ручную настройку и наблюдаемый результат. Успешная сборка сама по себе не подтверждает поведение окон или готовность к распространению.

## Проверка наведения

Встроенное приложение вручную проверено на macOS 27 с закреплённым ярлыком Code: наведение открыло соответствующую папку без нажатия; переход курсора на popup оставил его открытым; после ухода курсора popup закрылся. Интегрированный AX hit-test сопоставил папку `BAE3D00D-7F1F-4BAB-A431-061AA6A44FF2`. Пользователь подтвердил правильную работу открытия, удержания и закрытия.

Сначала запись Accessibility была включена, но не соответствовала текущей ad-hoc сборке Xcode (`AXIsProcessTrusted()` вернул false, а TCC записал несовпадение code requirement). После удаления устаревшей записи и повторного добавления текущей сборки `DockFolders.app` проверка доверия стала успешной после возврата в приложение. Новую ad-hoc сборку может потребоваться снова добавить в «Конфиденциальность и безопасность» → «Универсальный доступ». Для распространения нужна стабильная подпись.

Переключение между соседними папками, fallback без разрешения, энергопотребление при активном наведении, несколько дисплеев, перемещение/перезапуск Dock, автоскрытие, увеличение значков и полноэкранные приложения пока не проверены.

В Xcode Instruments записан 20-секундный Activity Monitor trace: режим наведения был выбран, но разрешение Accessibility не выдано. После начального запуска значения CPU оставались 0,0%, физический объём памяти составлял около 79 МиБ. Это замер без активного детектора наведения; он не описывает расход энергии при движении курсора над Dock.
