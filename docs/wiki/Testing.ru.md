# Тестирование

## Записанные результаты проверок

- Схема macOS успешно собрана в Xcode 27.1 / SDK 27.0.
- Пройдены 19 модульных тестов, включая проверку квадратного исходного изображения ярлыка 1024 × 1024 px при разрешении 2× (512 pt), расчёты popup для всех краёв Dock, миграцию JSON, проверку URL, создание ярлыков, сортировку, перенос конфигурации, хранение, поиск и ошибки запуска.
- Ручная проверка UI: создана папка, найден и добавлен Calculator, приложение запущено, сохранение папки подтверждено после перезапуска.
- Ручная проверка ярлыка: приложение открыто через Finder и выбрало папку Code как при запущенном DockFolders, так и после холодного старта.

## Явно не проверено

Фактическое положение и обрезка popup на нескольких физических дисплеях, все стороны Dock, скрытый/автоматически скрываемый Dock и подключение/отключение дисплея; VoiceOver, работа только с клавиатурой и уменьшение движения; регистрация/отмена запуска при входе через перезапуск; конфликты горячих клавиш; очистка устаревших значков Dock; подпись/нотариальное заверение/sandbox/распространение; инструкции закрепления на чистой установке пока не проверены. Расчёты геометрии краёв Dock покрыты модульными тестами; работу на реальном хосте ещё нужно проверить вручную.

## Оставшаяся матрица

- Popup: доступная геометрия экрана у всех сторон Dock, скрытый Dock, несколько дисплеев, отключение/подключение и изменение масштаба.
- Настройки: включение/отключение запуска при входе/ошибка после перезапуска; конфликт и повторная регистрация горячей клавиши.
- Интерфейс/доступность: клавиатура, VoiceOver-подписи, размер текста, контраст и уменьшение движения.
- Ярлыки: переименование/удаление, предупреждение об устаревшем Dock-элементе, установка/обновление/удаление вне среды разработки.
- Выпуск: подпись/нотариальное заверение, выбранная политика sandbox, чистая пакетная установка/обновление/удаление.

Выполняйте только проверки, поддерживаемые окружением; записывайте ручную настройку и наблюдаемый результат. Успешная сборка сама по себе не подтверждает поведение окон или готовность к распространению.
