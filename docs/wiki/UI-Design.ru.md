# Дизайн интерфейса

Все фиксированные надписи интерфейса, пояснения, диалоги, справочные тексты, подписи доступности и ошибки приложения переведены на английский и русский. macOS выбирает локализованные ресурсы с учётом предпочтительных языков пользователя. Для количества приложений применяются локальные правила множественного числа.

## Реализовано

SwiftUI используется для управления папками/настройками и сетки приложений, а AppKit — для popup с учётом Dock и macOS 27 Liquid Glass. Всплывающая папка теперь занимает одну компактную стеклянную панель; значки приложений и короткие подписи показаны без отдельных карточек. Сетка содержит до четырёх колонок, сохраняет встроенный поиск и прокручивается для больших папок. Положение окна выбирается по дисплею нажатого значка Dock и адаптируется к расположению Dock снизу, слева или справа. Для папки и ярлыка Dock доступен поиск по категориям SF Symbols, набор готовых цветов и системный выбор цвета. Исходное изображение ярлыка — квадратное, без маски, 1024 × 1024 px с разрешением 2× (512 pt); это соответствует [рекомендациям Apple по значкам приложений](https://developer.apple.com/design/human-interface-guidelines/app-icons); AppKit различает число пикселей и размер представления в пунктах ([`NSImageRep.size`](https://developer.apple.com/documentation/appkit/nsimagerep/size)); macOS масштабирует его для системных элементов; папки и приложения можно менять местами перетаскиванием. Размер сетки/значков и тема настраиваются. Панель закрывается через Escape, при потере фокуса или успешном запуске приложения. Поведение на нескольких физических дисплеях, доступность и уменьшение движения не проверены.

## Оставшиеся проверки дизайна

- Проверить расположение у каждого направления Dock и поддерживаемые конфигурации дисплеев.
- Проверить понятные состояния пустого содержимого, загрузки, поиска, недоступных приложений и ошибок.
- Проверить светлую/тёмную тему, контраст, клавиатурную навигацию, подписи доступности, VoiceOver и уменьшение движения.
- Проверить, что анимация не мешает взаимодействию или доступности.

Не имитируйте закрытую реализацию Dock и не полагайтесь на изменение системного Dock. Критерии приёмки приведены в [плане реализации](Implementation-Plan.ru.md).
