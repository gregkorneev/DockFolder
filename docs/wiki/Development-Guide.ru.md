# Руководство по разработке

## Требования

Используйте Xcode и macOS 27 SDK, режим Swift 6, SwiftUI и публичные API AppKit. Результаты проверки хоста записаны в [окружении](Environment.md), команды сборки приведены в [README](../../README.md).

## Рабочий процесс

1. Перед изменением поведения прочитайте [архитектуру](Architecture.md), [решения](Decisions.md) и страницу затрагиваемого компонента.
2. Разделяйте модели, интерфейс и интеграции с ОС. Добавляйте протоколы там, где они упрощают тестирование.
3. Выполняйте небольшие, проверяемые этапы дорожной карты.
4. Добавляйте или обновляйте тесты для значимого поведения; вручную проверяйте поведение окон ОС, если автоматизация не может его подтвердить.
5. Обновляйте соответствующую страницу Wiki, [дорожную карту](Roadmap.md), [известные проблемы](Known-Issues.md) и статус истории изменений.
6. Собирайте/тестируйте схему Xcode и сообщайте, что именно было проверено.

## Правила платформы

- Используйте публичные API и проверяйте их в выбранном SDK.
- Не изменяйте настройки Dock и не автоматизируйте действия пользователя с Dock.
- Обеспечьте миграцию сохранённых данных и сохраняйте данные, если чтение или импорт завершается ошибкой.
- Сообщайте пользователю о недоступных приложениях и ошибках регистрации средствами ОС.
- Обеспечьте доступность всех интерактивных элементов с клавиатуры и добавьте подписи.
- Не устанавливайте и не обновляйте инструменты/зависимости автоматически.

## Текущее и запланированное

В коде есть ярлыки отдельных папок, всплывающее окно, настройка порядка и внешнего вида папок, параметры, горячая клавиша, запуск при входе, перетаскивание, импорт и экспорт. Оставшиеся проверки выпуска перечислены в [плане реализации](Implementation-Plan.md) и [тестировании](Testing.md). Не заявляйте об успешной проверке сценариев конкретной машины, если её не проводили на этом хосте.
