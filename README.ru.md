# DockFolders

DockFolders — нативное приложение macOS для организации установленных программ в пользовательские папки и запуска их из Dock. В текущей версии реализованы основные функции версии 1.0; проверка совместимости с платформой и готовности к распространению ещё не завершена.

## Реализованные функции

- Создание, переименование и удаление папок.
- Поиск установленных приложений и добавление/удаление их из папок.
- Запуск приложений из папки.
- Локальное сохранение папок и настроек между запусками.
- Интерфейс и стандартные сообщения приложения локализованы на английский и русский; macOS выбирает язык по предпочтительным языкам пользователя.
- Нативный интерфейс SwiftUI с визуальными материалами macOS 27.
- Выбирайте значок папки и ярлыка Dock из категорий SF Symbols с поиском; задавайте фон готовым цветом или через системную палитру. Исходное изображение значка Dock квадратное, без маски: 1024 × 1024 px при разрешении 2× (512 pt), macOS масштабирует его под Dock. Меняйте порядок папок и приложений перетаскиванием.
- Компактное всплывающее окно Liquid Glass привязано к месту нажатия значка Dock на соответствующем дисплее и адаптируется к расположению Dock снизу, слева или справа.
- Скрывайте или показывайте названия приложений, выбирайте подходящую количеству приложений сетку либо один ряд/столбец для каждой папки. Неподходящие сетки скрываются, размеры подбираются динамически. В настройках можно создавать именные пресеты; выбранный пресет применяется к новым папкам.
- Настройки сетки, размера значков и темы; глобальное сочетание Control–Option–Space и запуск при входе в систему.
- Импорт и экспорт конфигурации.
- Для каждой папки в `/Applications/DockFolders` создаётся приложение-ярлык с названием папки (при совпадении добавляется номер); переименование обновляет имя ярлыка, сохраняя стабильную ссылку `dockfolders://folder/<UUID>`.

Чтобы выбрать её значок, нажмите правой кнопкой на папку в боковом меню и выберите **Настроить папку и значок Dock…**. Чтобы закрепить папку в Dock, создайте для неё ярлык в DockFolders, откройте созданное приложение из `/Applications/DockFolders` в Finder, затем выберите в меню значка Dock **Options → Keep in Dock**. macOS требует выполнить закрепление вручную; DockFolders не изменяет настройки Dock. Расчёты позиции для разных краёв покрыты модульными тестами; поведение на реальных нескольких дисплеях и со скрытым Dock, доступность и уменьшение движения, фактическая регистрация запуска при входе, конфликты сочетаний клавиш, а также подпись и нотариальное заверение требуют дополнительной проверки на системе.

## Требования

- macOS 27.0 или новее, Apple Silicon.
- Xcode 27.1 или новее с macOS SDK.

Откройте `DockFolders.xcodeproj` в Xcode, выберите схему DockFolders и назначение My Mac, затем выполните сборку и запуск. Проверка из командной строки:

```sh
xcodebuild -list -project DockFolders.xcodeproj
xcodebuild -project DockFolders.xcodeproj -scheme DockFolders -destination 'platform=macOS' build
xcodebuild -project DockFolders.xcodeproj -scheme DockFolders -destination 'platform=macOS' test
```
