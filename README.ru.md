# DockFolders

DockFolders — нативное приложение macOS для организации установленных программ в пользовательские папки и запуска их из Dock. В текущей версии реализованы основные функции версии 1.0; проверка совместимости с платформой и готовности к распространению ещё не завершена.

## Реализованные функции

- Создание, переименование и удаление папок.
- Поиск установленных приложений и добавление/удаление их из папок.
- Запуск приложений из папки.
- Локальное сохранение папок и настроек между запусками.
- Интерфейс и стандартные сообщения приложения локализованы на английский и русский; macOS выбирает язык по предпочтительным языкам пользователя.
- Нативный интерфейс SwiftUI с визуальными материалами macOS 27.
- В качестве значка DockFolders используется предоставленный рисунок папки с сеткой приложений: светлый PNG 1024 × 1024 установлен без редактирования. Исходные редактируемые слои и варианты сохранены в [Design/DockFolders_IconComposer](Design/DockFolders_IconComposer/README.ru.md), а набор для импорта в Icon Composer 27.1 — в [Design/DockFolders_IconComposer_27_1_Import](Design/DockFolders_IconComposer_27_1_Import/README_Import_Icon_Composer_27.1.ru.md).
- Выбирайте значок папки и ярлыка Dock через поиск по каталогу из 7 752 названий SF Symbols 7 с категориями и крупным предпросмотром, включая символы устройств Apple; изображения рисует macOS через публичные API AppKit. Задавайте фон готовым цветом или через системную палитру. Исходное изображение значка Dock квадратное, без маски: 1024 × 1024 px при разрешении 2× (512 pt), macOS масштабирует его под Dock. Меняйте порядок папок и приложений перетаскиванием.
- Компактное всплывающее окно Liquid Glass привязано к месту нажатия значка Dock на соответствующем дисплее и адаптируется к расположению Dock снизу, слева или справа.
- При желании popup можно открывать наведением, нажатием или обоими способами. Для наведения используются публичные Accessibility API и требуется разрешение macOS «Универсальный доступ»; открытие нажатием работает и без него. Задержки открытия и закрытия настраиваются.
- Скрывайте или показывайте названия приложений и вводите от 1 до 10 строк и столбцов для каждой папки; лишние приложения доступны прокруткой. Именные пресеты можно выбрать для каждой папки отдельно. Новая папка получает стандартный макет.
- Настройки сетки, размера значков и темы; глобальное сочетание Control–Option–Space и запуск при входе в систему.
- Импорт и экспорт конфигурации.
- Для каждой папки в `/Applications/DockFolders` создаётся приложение-ярлык с названием папки (при совпадении добавляется номер); переименование обновляет имя ярлыка, сохраняя стабильную ссылку `dockfolders://folder/<UUID>`.
- Popup папок работают без постоянного значка Dock у управляющего приложения. Нажмите шестерёнку в popup, чтобы открыть управление папками: значок приложения появится в Dock на время открытого окна и исчезнет после его закрытия.

Чтобы выбрать её значок, нажмите правой кнопкой на папку в боковом меню и выберите **Настроить папку и значок Dock…**. Чтобы закрепить папку в Dock, создайте для неё ярлык в DockFolders, откройте созданное приложение из `/Applications/DockFolders` в Finder, затем выберите в меню значка Dock **Options → Keep in Dock**. macOS требует выполнить закрепление вручную; DockFolders не изменяет настройки Dock. На macOS 27 сквозная работа закреплённого ярлыка Code проверена: наведение открывает папку, переход курсора в popup оставляет её открытой, уход закрывает. Несколько дисплеев и скрытый Dock, доступность и уменьшение движения, фактическая регистрация запуска при входе, конфликты сочетаний клавиш, а также подпись и нотариальное заверение требуют дополнительной проверки на системе.

При первом запуске откроется вводное руководство; позже его можно вызвать через меню «Справка».

Если само приложение DockFolders уже закреплено, вручную выберите для него **Options → Remove from Dock**: macOS оставляет пользовательскую закреплённую копию независимо от открытого окна. В Dock следует оставить ярлыки папок.

## Требования

- macOS 27.0 или новее, Apple Silicon.

## Версия для разработки

Beta 3 доступна в виде DMG для Apple Silicon на [странице релизов GitHub](https://github.com/gregkorneev/DockFolder/releases). Разработка продолжается в `main`.

Для сборки из исходников используйте Xcode 27.1 или новее с macOS 27 SDK.

Откройте `DockFolders.xcodeproj` в Xcode, выберите схему DockFolders и назначение My Mac, затем выполните сборку и запуск. Проверка из командной строки:

```sh
xcodebuild -list -project DockFolders.xcodeproj
xcodebuild -project DockFolders.xcodeproj -scheme DockFolders -destination 'platform=macOS' build
xcodebuild -project DockFolders.xcodeproj -scheme DockFolders -destination 'platform=macOS' test
```
