# История изменений

## Не выпущено — разработка

- При создании значка ярлыка вторичный слой SF Symbols остаётся прозрачным: например, `macbook` сохраняет контур из выбора значка вместо цветной заливки экрана.
- Значок DockFolders исчезает из Dock при открытии popup папки из окна управления; высота содержимого popup теперь позволяет показывать значки приложений целиком при любом выбранном макете.
- Все SF Symbols в выборе значка сгруппированы по категориям; их предпросмотр увеличен.
- Убрана настройка макета для новых папок: новая папка получает стандартную сетку, а сохранённые пресеты можно выбрать для каждой папки отдельно.
- При первом обычном запуске показывается вводное руководство из четырёх экранов; его можно повторно открыть через меню «Справка».
- Уменьшать горизонтальные и вертикальные отступы сетки вместе со значками, чтобы в той же области popup помещалось больше приложений.
- Управляющее приложение больше не занимает Dock постоянно: шестерёнка в popup открывает управление папками и показывает его значок в Dock только пока окно открыто.
- Открытая при наведении папка не закрывается, пока открыты её настройки макета. Убраны видимые подписи строк и столбцов; размер сетки popup теперь меняется вслед за ползунком размера значков.
- Ячейки пользовательской сетки растягиваются по ширине popup, а выбранное число строк и столбцов целиком помещается на экране. Выбранная вместимость видна без прокрутки; прокручиваются только приложения сверх неё, а на маленьких дисплеях значки и подписи уменьшаются.

## 2026-10-20 — 1.0.0 Beta 2

- В меню макета каждой папки добавлен ввод числа строк и столбцов от 1 до 10. Пользовательская сетка сохраняет выбранный размер; лишние приложения и содержимое за пределами экрана доступны прокруткой.

- В настройках наведения показано фактическое состояние доступа к «Универсальному доступу» для текущей сборки; после выдачи разрешения мониторинг запускается повторно. Пересборка приложения с временной подписью может потребовать повторного разрешения.

- Исправлено открытие наведением, когда Dock появляется под неподвижным курсором: адаптивный таймер повторно проверяет значок даже при установленном глобальном мониторе мыши.

- При открытии устаревшей или неверной ссылки папки сохраняется исходное сообщение об ошибке чтения данных, чтобы причина проблемы оставалась видна.

- Исправлено удаление папки при ошибке сохранения: её ярлык сохраняется, если запись данных не удалась, и удаляется только после успешной записи. Старая ошибка больше не перенаправляет корректную ссылку папки в главное окно; popup показывает сообщение об ошибке. При запуске уже установленные актуальные ярлыки не пересоздаются.

- Увеличен нижний отступ popup под значками приложений.
- Исправлено краткое появление главного окна при открытии ярлыка папки: обработка URL больше не зависит от обозревателя, а окно AppKit создаётся только при обычном запуске, явном повторном открытии или показе ошибки. Добавлены регрессионные тесты; визуальная проверка холодного запуска ещё требуется.

## 2026-10-20 — 1.0.0 Beta 1

- В меню «Макет папки» добавлены индивидуальные настройки размера значков, столбцов сетки и прозрачности стекла. Каждая папка хранит собственные параметры отображения вместо общих настроек приложения.
- Динамические квадратные сетки расширены с 1 × 1 до 10 × 10: показываются только размеры, вмещающие все приложения папки. Для папок с более чем 100 приложениями предлагаются и более крупные подходящие сетки.
- Исправлен контраст названия выбранной папки в боковом меню для светлой и тёмной тем.
- Установлен предоставленный `Preview_Light.png` как значок DockFolders без редактирования изображения; исходный многослойный эскиз сохранён для дальнейшей работы в Icon Composer.
- Вместо небольшого вручную собранного набора добавлен поиск по каталогу SF Symbols 7.0 (7 752 идентификатора), включая символы устройств Apple; изображения предоставляет macOS во время работы.
- Добавлен выбор значков папки и Dock из категорий SF Symbols с поиском, готовые фоны и системная палитра цветов; значки ярлыков теперь входят в `.app` как стандартные многослойные по разрешению `.icns`, собранные из изображения 1024 × 1024 px, поэтому macOS применяет к ним обычное оформление Dock. Размер плитки и увеличение по-прежнему задаются настройками Dock в macOS.
- Имя каждого ярлыка Dock теперь соответствует названию папки; UUID-маршрут сохраняется, одинаковые названия получают читаемый числовой суффикс, а переименование обновляет имя ярлыка.
- Проверено окружение проекта; подтверждены Xcode 27.1 и macOS SDK 27.
- Зафиксированы начальная архитектура и план MVP.
- Добавлено нативное приложение macOS на SwiftUI с созданием, переименованием и удалением папок.
- Добавлены поиск установленных приложений, выбор файла как резервный способ, добавление/удаление и запуск через `NSWorkspace`.
- Добавлено версионированное атомарное сохранение JSON с безопасной обработкой ошибок.
- Добавлены повторное открытие окна из Dock и сетка приложений Liquid Glass.
- Добавлены настройка SF Symbol и цвета папки, а также ручное изменение порядка перетаскиванием.
- Добавлено всплывающее окно Liquid Glass с учётом Dock, закрываемое клавишей Escape, при потере фокуса и после успешного запуска; добавлены настройки сетки, размера значков, темы, запуска при входе и глобального сочетания клавиш.
- Добавлен импорт и экспорт конфигурации.
- Добавлена локализация интерфейса на английский и русский языки, включая правила русских форм множественного числа.
- Добавлено приложение-ярлык для каждой папки в `/Applications/DockFolders`; проверены ссылки `dockfolders://folder/<UUID>` при уже запущенном DockFolders и при холодном запуске.
- Добавлены русские версии README, инструкций участникам, истории изменений, аудита окружения и всех страниц Wiki; английские и русские документы связаны между собой.
- Компактнее оформлено всплывающее окно папки: уменьшены значки без карточек, добавлены подписи, встроенный поиск и прокручиваемая сетка максимум на четыре колонки.
- Popup позиционируется на дисплее нажатого значка Dock и учитывает Dock снизу, слева, справа и автоскрытие; добавлены тесты геометрии.
- Добавлена анимация раскрытия popup от значка Dock и сворачивания обратно; при включённом в macOS «Уменьшении движения» переход отключается.
- Добавлены настройка видимости названий и макета каждой папки (сетка, один ряд или столбец), а также конструктор пресетов; выбранный пресет автоматически используется для новых папок.
- Список сеток popup теперь учитывает количество приложений: варианты с недостаточным числом ячеек скрываются, а при необходимости автоматически предлагаются более крупные сетки.
- Пройдены 22 модульных теста, включая подбор вместимости сетки и её автоматическое увеличение, миграцию прежнего формата JSON, проверку URL, создание приложения-ярлыка, сортировку и перенос конфигурации.
- Вручную проверен запуск ярлыка из Finder: папка Code открылась, когда DockFolders уже работал, и после холодного запуска.
- Пока не проверены: визуальное поведение анимации на нескольких дисплеях и у всех сторон Dock, доступность, фактическая регистрация запуска при входе, конфликты сочетаний клавиш, подпись/нотариальное заверение/песочница/распространение и закрепление в Dock на чистой установке.

### 2026-10-20 — Открытие наведением

- Исправлено появление главного окна при запуске по ярлыку папки: отключено восстановление старого окна, а обработчик URL скрывает стандартные окна перед показом popup.
- На macOS 27 подтверждено живое обнаружение элемента Dock через глобальные события движения курсора и публичный Accessibility API.
- Добавлены режимы «По нажатию» / «При наведении» / «По нажатию и наведению», настраиваемые задержки, объяснение запроса «Универсального доступа» и событийное управление popup с адаптивным редким резервным опросом.
- Размер popup теперь рассчитывается по доступной области дисплея и числу приложений; при нехватке места макет адаптируется к сетке без прокрутки значков. Добавлена проверка адаптивного расчёта.
- В собранном приложении проверено: наведение на Code открывает папку, переход на popup оставляет её открытой, а уход курсора закрывает окно.
- Открытие нажатием остаётся режимом по умолчанию; переключение соседних папок, режим без разрешения, активное энергопотребление и альтернативные конфигурации Dock/дисплеев требуют проверки.
