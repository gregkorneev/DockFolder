# DockFolders — безопасный импорт в Apple Icon Composer 27.1

## Почему предыдущий AppIcon.icon не открылся

Предыдущий `AppIcon.icon` был собран вручную по неофициальному формату `icon.json`.
Icon Composer 27.1 отклонил его. Это ошибка подготовленного пакета.

В наборе сохранён черновой пакет `Drag_to_Icon_Composer/Untitled.icon`. Его открытие и сохранение в Icon Composer 27.1 не проверялись; он не используется целью Xcode. Для надёжного импорта создайте новый документ `.icon` в Apple Icon Composer и загрузите в него подготовленные слои.

## Вариант 1 — самый надёжный

1. Запустите **Icon Composer** 27.1 на Mac.
2. **File → New** (Файл → Новый). При необходимости выберите только платформу macOS в настройках документа.
3. **File → Save** и сохраните новый документ с именем `AppIcon.icon`.
4. В редакторе нажмите **+ → New Image** (Создать изображение / Новое изображение).
5. Импортируйте **в таком порядке** три SVG из `Layers_SVG`:
   - `01_FolderBack.svg` — задняя часть папки;
   - `02_FolderFront.svg` — передняя часть папки;
   - `03_AppGrid.svg` — четыре плитки приложений.
6. Поместите файлы в отдельные группы, если хотите управлять стеклом каждого слоя независимо.
7. В левой панели порядок от заднего к переднему: 01 → 02 → 03.
8. Выделите верхний уровень документа, задайте нежный светлый фон (например, #F2F7FF) для Default и тёмный фон для Dark. В Mono проверьте читаемость четырёх плиток.
9. Для групп задайте нужные параметры Liquid Glass, преломления, теней и отражений с помощью Icon Composer (без заранее нанесённых эффектов).
10. Сохраните `AppIcon.icon`. Его создал сам Icon Composer, поэтому внутренний формат соответствует установленной версии.

**Альтернативный ввод**: перетащите три каталога из `Drag_to_Icon_Composer` в левую панель Icon Composer. По инструкции Apple, вложенные файлы становятся слоями, а папки — группами. Проверьте их порядок.

## Вариант 2 — если SVG не импортируются

Используйте одноимённые прозрачные PNG 1024 × 1024 из `Layers_PNG`.
Координаты слоёв идентичны. Все файлы имеют прозрачный фон.

## Использование в Xcode

Добавьте **созданный в Icon Composer** `AppIcon.icon` в навигатор проекта Xcode.
В настройках target → General → App Icons and Launch Screen укажите `AppIcon`.
Это будет родной редактируемый файл Icon Composer. Если в проекте есть старый AppIcon из Assets.xcassets, проверьте, что назначен нужный значок.

## Что проверено, а что нет

- SVG: валидный XML, одинаковый холст 1024 × 1024.
- PNG: успешно отрисованы в 1024 × 1024 и содержат прозрачность.
- Базовый состав и порядок трёх слоёв проверены.
- Проверка открытия/сохранения через Apple Icon Composer 27.1 **не выполнялась**, потому что на стороне подготовки нет macOS.
- Файлы в `Previews` — статические иллюстрации, а не фактический рендер Icon Composer.
