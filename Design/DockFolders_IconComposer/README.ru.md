# Эскиз значка DockFolders

В этой папке сохранены предоставленные эскизы и слои для дальнейшей доработки. Три SVG-файла в `SourceLayers/` — редактируемые слои; PNG-файлы — предварительные изображения.

## Текущий значок

`Preview_Light.png` установлен как значок приложения DockFolders для macOS без изменений изображения. Копия в каталоге ресурсов побайтно совпадает с исходником. Тёмный вариант сохранён для дальнейшей работы, но пока не подключён как вариант оформления.

## Состояние пакета Icon Composer

Предоставленный пакет `AppIcon.icon` был открыт в Icon Composer 27.1, но приложение отклонило его: данные не соответствуют ожидаемому формату. Пакет сохранён как черновик, однако цель Xcode его не использует. Чтобы позднее применить многослойный вариант, создайте корректный документ в Icon Composer и импортируйте неизменённые SVG-файлы из `SourceLayers/`.

Руководство Apple: [Создание значка приложения с помощью Icon Composer](https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer).
